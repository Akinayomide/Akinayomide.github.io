## Project
### [Nexora Returns Impact Analysis](https://github.com/Akinayomide/nexora-returns-impact-analysis)

Analyzed product returns at Nexora Stores using Microsoft Excel and Power BI to understand their impact on sales and profitability. Investigated return trends over time, identified products and regions contributing to increased returns, and examined the financial impact on the business. Presented the findings through an interactive Power BI dashboard, highlighting key areas of concern and providing actionable recommendations to help management reduce returns and improve business performance.
